# Eve Plants media register

This register makes later permission and attribution work explicit. Before a commercial public launch, contact each creator, confirm permission for local hosting and edited excerpts, and record the response here. If permission is declined, replace the corresponding files and page references.

## YouTube-derived editorial media

The site uses silent seven-second excerpts and still frames extracted with `yt-dlp` and FFmpeg. The downloaded working source section for each video was approximately `00:02:00–00:02:20`; only the optimized outputs under `assets/` are committed.
